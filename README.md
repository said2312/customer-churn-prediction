# Customer Churn Prediction

A machine learning project that predicts which customers are likely to churn (stop using a service), so a business can act on retention before customers leave.

The full workflow (data loading, exploration, preprocessing, model training and evaluation) is in the Jupyter notebook `churnprediction.ipynb` 

## What the notebook covers

- Loading and inspecting the customer dataset
- Cleaning and preparing the data
- Exploratory analysis of customer behavior
- Training classification models to predict churn
- Evaluating model performance

## Getting started

```bash
git clone https://github.com/said2312/customer-churn-prediction.git
cd customer-churn-prediction
python -m venv venv
venv\Scripts\activate
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
jupyter notebook churnprediction.ipynb
```

Run the cells from top to bottom to reproduce the analysis.

## Tech stack

Python, Jupyter Notebook, pandas, NumPy, scikit-learn, Matplotlib, Seaborn
